# Emoji translation file
#
# I expect many of these to not be useful and need refinement, I already added extra phrases like "fox" that is a duplicate of "fox face"
# since otherwise you'll probably never see the fox emoji. Many other phrases are never used and probably need a better phrase to make use
# of the emojis. The best way to figure it out is to look through the unicode emoji table http://unicode.org/Public/emoji/5.0/emoji-test.txt
# to know what emoji are available. Then when you see text online that you know there's an emoji for, you can add it to the table!
#
# I also think many items can use a plural phrase. Otherwise "dogs" gets no emoji, but "dog" does, and it's a bit confusing.
#
# This whole thing could also just wind up being rather stupid or have a much more limited scope, but it's fun to try!
#
# Lines starting with a # are comments
# Blank lines are ignored
# The search text is not case sensitive
#
# Most lines are the following:
# <emoji> <space> <search text> (, <second search text>)*
#
# This allows for an emoji, and any number of synonyms for it that should use the same emoji.
#
# The default is to append the emoji after the original text, otherwise text becomes very hard to understand.
# If replacement is desired, like for the smiley emoticons, put them within a 'REPLACE_BEGIN/REPLACE_END' block
